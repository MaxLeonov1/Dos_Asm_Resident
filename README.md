# TSR Register Monitor

---
### Russian Description:

Резидентная программа (TSR), предназначенная для мониторинга значений регистров процессора, и вывода их на экран в графическом представлении. Работает посредством перехвата прерываний (int 09h и int 08h).

### Требования
* Процессор: Intel 80286.
* ОС: MS-DOS / DOSBox.
* Видеорежим: Текстовый 80x25.

### Сборка и запуск
Для ассемблирования требуется TASM.

1. **Ассемблирование**: `tasm /la reg_res.asm`
2. **Линковка**: `tlink /t reg_res.obj`
3. **Запуск**: `reg_res.com`.

### Управление
* **Left Shift**: Открытие окна или обновление значений регистров.
* **Right Shift**: Скрытие окна и восстановление экрана.
* **Выгрузка Резидента**: В данной версии выгрузка возможна только с использование внешних утилит, или перезапука ОС.

### Подробности реализации
* **Первый запуск**: Программа подменяет адреса системных прерываний [Int09](./REG_RES.ASM#L353) и [Int08](./REG_RES.ASM#365), на новые [NewInt08](./REG_RES.ASM#L37) и [NewInt09](./REG_RES.ASM#L93), при этом функции системных прерываний сохраняются т.к. при вызове новых прерываний они также при исполнении вызывают старые.
* **Описание NewInt08**: Задача этой процедуры это проверка данных видеопамяти на изменение во время того как рамка регистров отрисованна на экране. В случае если видеопамять "за рамкой" изменилась то процедура сохраняет изменения в [save_buffer](./REG_RES.ASM#L66). Так же эта процедура вызывает исходное перехваченое [прерывание](./REG_RES.ASM#L39).
* **Описание NewInt09**: Задача этой процедуры это: запомнить значение [регистров](./REG_RES.ASM#L98), обработать нажатие [клавиш](./REG_RES.ASM#L118), отрисовать/обновить рамку, или наоборот обновить экран и убрать рамку (в зависимости от нажатых клавиш), в конце вызвать перехваченое [прерывание](./REG_RES.ASM#L146) чтобы клавиатура оставалась функциональной. Для отрисоки рамки регистров и работы с видеопамятью используются **дополнительные функции:**
  * **[RestoreScreen](./REG_RES.ASM#L182)**: Перезаписывает сохраненную область экрана (из save_buffer) в видеопамять.
  * **[SaveScreen](./REG_RES.ASM#L156)**: Записывает определённую область (12x14 по центру с отступом в 5 рядов от верха) экрана (в save_buffer) из видеопамяти.
  * **[CopyBufferToScreen](./REG_RES.ASM#L208)**: Перезаписывает область экрана рамкой с регистрами из draw_buffer.
  * **[DrawFrame](./REG_RES.ASM#L234)**: Сохраняет рамку заднную определёнными символами в draw_buffer.
  * **[PrintRegisters](./REG_RES.ASM#L283)**: Записывает в draw_buffer названия регистров (с помощью [PrintHEXWord](./REG_RES.ASM#L323)) и их сохраненные значения.
